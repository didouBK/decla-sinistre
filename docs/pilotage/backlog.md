# Backlog priorisé

Source structurée: backlog.csv. MoSCoW exprime la priorité métier: MUST pour dépôt minimum, SHOULD pour pièces, COULD pour suivi simplifié; aucune WON’T n’est engagée. Story points = estimation relative, jamais heures.

Les huit stories sont suivies dans le CSV. Tâches techniques: initialiser prototype, validation d’entrées, génération référentiel/exports, contrôles CI, documentation, revue clavier/responsive, tests de non-régression. Une story est terminée lorsque ses critères sont vérifiables, cas liés exécutés et résultat tracé, documentation alignée et aucune anomalie bloquante ouverte. Les états sont simulés.
