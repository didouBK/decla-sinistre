# Prototype DéclaSinistre

Ouvrir index.html dans un navigateur moderne, ou lancer python3 -m http.server 8000 depuis ce dossier et visiter http://localhost:8000. Parcours cinq écrans, validation locale, fichiers non transmis, référence et statut de démonstration. Les données sont fictives; ne saisir aucune donnée personnelle. Le suivi persiste uniquement une référence/status dans localStorage.
